### РАСПРЕДЕЛЕНИЕ ПУНКТОВ

Определив ключевые части прошлого персонажа, реши, насколько хорошо он проявляет себя в разных областях.
Чем больше пунктов вложено в параметр, тем выше соответствующая компетенция.

В таблице «[[Распределение пунктов|Распределение пунктов]]» указано, сколько пунктов можно потратить в каждой категории. Помни: выбранный вид [[Ночные существа|ночного существа]] определяет максимальное значение каждого параметра, кроме [[Навыки|Навыков]]. Как указано ниже, при создании персонажа ни один [[Навыки|Навык]] не может превышать 3 пунктов.

**[[Жизненный путь|Жизненные пути]].** Количество Жизненных путей при создании персонажа.

**[[Характеристики|Характеристики]].** Количество пунктов для распределения по трём категориям [[Характеристики|Характеристик]].
Каждое число в столбце назначается отдельной категории.

**[[Дисциплина|Дисциплины]].** Количество пунктов, распределяемых между клановыми [[Дисциплина|Дисциплинами]] при создании персонажа. Не забудь о дополнительном пункте от [[Сир|сира]] на шаге 3; в таблице он записан как «+1».

**Силы [[Дисциплина|Дисциплин]].** Количество сил, выбираемых при создании персонажа. Чтобы изучать силы [[Дисциплина|Дисциплины]], в ней должен быть хотя бы 1 пункт. [[Уровень|Уровень]] выбранной силы не может превышать количество пунктов в этой [[Дисциплина|Дисциплине]].

**[[Достоинство|Достоинства]].** Количество [[Достоинство|Достоинств]] при создании персонажа.

**[[Клановая черта|Клановые черты]].** Количество клановых черт при создании персонажа.

**[[Навыки|Навыки]].** Количество дополнительных пунктов [[Навыки|Навыков]] помимо полученных на шаге 4.

**[[Ресурсы|Ресурсы]].** Количество дополнительных пунктов [[Ресурсы|Ресурсов]] помимо полученных на шаге 4.
