## [[Пакет игрока|Пакет игрока]]

**Сложность.** Число, отражающее трудность задачи. При [[Проверка|проверке]] оно вычитается из [[Пул проверки|пула проверки]].


## [[Пакет игрока|Пакет игрока]]

### СЛОЖНОСТЬ

Сложность [[Проверка|проверки]] показывает, насколько трудно выполнить задачу. Чем она выше, тем меньше вероятность [[Успех|успеха]]. Помни: для простых и безопасных задач сложность не определяется, поскольку они вообще не требуют [[Проверка|проверки]] (см. раздел «[[Применение правил (принцип)|Применение правил]]»).

Сложность задачи определяет, сколько костей удаляется из начального [[Пул проверки|пула проверки]]. [[Пул проверки|Пул проверки]] не может опуститься ниже 0.

Сложность = количество костей, удаляемых из начального [[Пул проверки|пула проверки]].


## [[Пакет игрока|Пакет игрока]]

**Сложность.** Число, обозначающее трудность выполнения определённой задачи. При прохождении [[Проверка|проверки]] оно вычитается из [[Пул проверки|пула проверки]].
