## РАНГ

У каждой Силы есть обозначенный пунктами [[Ранг|ранг]], отражающий её могущество относительно других Сил [[Дисциплина|Дисциплин]]. Многие эффекты используют [[Ранг|ранг]] для определения Сложности преодоления Силы. Если ты противодействуешь активной Силе, воздействующей на существо, вместо фиксированной Сложности проводится состязание [[Проверка|проверок]] Силы с её создателем.

Например, если [[Носферату|носферату]] скрывает [[Предметы|предмет]] Силой Сокрытия, [[Ранг|ранг]] этой Силы определяет Сложность его обнаружения с помощью «Потустороннего зрения».
Если могущественный [[Вентру|вентру]] затуманил твои воспоминания, для снятия этого эффекта с помощью «Очищения» необходимо провести состязание [[Проверка|проверок]] Силы с применившим его вампиром.

**Усиление.** [[Предметы|Предмет]], на который воздействует Сила с элементом «Усиление», использует [[Ранг|ранг]] Усиления, доступный создателю Силы в момент её применения, вместо базового [[Ранг|ранга]].
